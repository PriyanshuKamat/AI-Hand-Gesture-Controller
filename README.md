# 🚀 AI Hand Gesture Controller

A real-time Python application that allows users to control system volume, screen brightness, media playback (Play/Pause), and audio mute/unmute using hand gestures powered by **OpenCV** and **MediaPipe**. 

Optimized for smooth performance on low-end/older hardware!

---

## ✨ Features
* **Volume Control:** Pinch/adjust distance between Thumb & Index finger.
* **Brightness Control:** Pinch/adjust distance between Thumb & Ring finger.
* **Play / Pause:** V-Sign (Victory Gesture).
* **Mute / Unmute:** Fist (Mukka).
* **Lock / Unlock Mode:** 3-Fingers Up (Prevents accidental triggers when not in use).
* **Performance Boost:** Configured with lightweight model complexity (`model_complexity=0`) to maintain high FPS on older laptops.

---

## 🛠️ Tech Stack & Requirements
* **Python Version:** Python 3.11 (Tested & Fully Working)
* **Libraries:**
  * OpenCV
  * MediaPipe
  * Pycaw (Windows Audio Control)
  * Screen Brightness Control
  * PyAutoGUI
  * NumPy
